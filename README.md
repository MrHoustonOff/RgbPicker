# RgbPicker

RgbPicker is the first stable release of a lightweight tool that allows you to easily check the RGB values of any pixel on your screen using customizable hotkeys. This release includes essential features such as real-time RGB value display, system tray support, and a settings menu for fine-tuning.

## Installation

To get started, visit the [Releases](https://github.com/MrHoustonOff/RgbPicker/releases) page and download the latest `.exe` file. Simply run it, and you're good to go!

## Default Hotkeys
- **Ctrl + Shift**: Activate the main functionality (pixel color picker).
- **Ctrl + Alt + I**: Open the settings menu.

To close the application, simply exit via the system tray.

## Settings Menu

Through the system tray or hotkeys, you can access the settings menu where you can:
1. **Slider**: Adjust the update frequency in milliseconds (lower for faster updates). Recommended value: ~15 ms (approximately 60 FPS).
2. **Custom Hotkey**: Set a custom hotkey for the main functionality. Use the format `key1+key2+key3+...`.
3. **Save Settings**: Save your customizations.

Feel free to download and modify the project to suit your needs!
